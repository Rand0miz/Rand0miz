# Setup — variant 2 (terminal / phosphor)

An alternative profile README. Pick **this one or `../github-profile`**, not both — they target the
same repo (`Rand0miz/Rand0miz`).

```
github-profile-v2/
├─ README.md
├─ assets/
│  └─ boot.svg       # animated TTY boot log (hand-written)
└─ .github/workflows/snake.yml   # regenerates the contribution snake every 12h
```

## Push

```bash
cd github-profile-v2
git init -b main
git add .
git commit -m "Add animated profile README"
git remote add origin https://github.com/Rand0miz/Rand0miz.git
git push -u origin main
```

If you already pushed variant 1, replace the files in the existing repo instead of `git init`.

## Turn on the snake

The snake image 404s until the workflow has run once.

1. Repo → **Settings → Actions → General → Workflow permissions** → *Read and write permissions*.
2. Repo → **Actions** → `generate contribution snake` → **Run workflow**.
3. It publishes `github-snake.svg` and `github-snake-dark.svg` to a branch called `output`.

After that it re-runs every 12 hours and on every push to `main`. The snake here is themed to the
phosphor palette (`#3fb950`) — that lives in the `outputs:` block of the workflow, not the README.

## Editing `boot.svg`

Generated by `gen_svg_v2.py` (kept outside this repo — copy it in if you want it versioned).

| what | where |
| :-- | :-- |
| boot log text | `LINES` — `(kind, label, value)`; `kind` is `cmd` / `ok` / `warn` / `bar` / `out` / `gap` |
| line timing | `d = 0.30 + i * 0.26` — seconds between lines printing |
| palette | `GREEN`, `AMBER`, `RED`, `DIM`, `FG`, `BG` constants at the top |

It carries `prefers-color-scheme` rules (the CRT scanline layer hides itself in light mode) and
`prefers-reduced-motion` rules that jump to the final frame.

> The generator also emits a second file, `pipeline.svg` — an animated context-compiler data path
> that this variant no longer uses. Delete that block at the bottom of `gen_svg_v2.py`, or the file
> reappears in `assets/` next time you run it.

## Caveats

- The boot log is **theatre** — the numbers come from your `sprucekit` runs, but nothing executes.
  Same for the `ps aux` block.
- Language percentages in the `tree` block are hand-typed; the live numbers are in the `cloc ~/`
  card right below.
- `github-readme-stats`, `github-profile-trophy`, `streak-stats`, `readme-typing-svg` and
  `shields.io` are third-party services and occasionally rate-limit. Images go blank; the page
  still renders.
- `include_all_commits=true&count_private=true` only reports private activity if you enable it in
  your GitHub profile settings.
